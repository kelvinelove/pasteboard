# Change Log

## 1.1.0

- Status Bar trigger (`$(clipboard) Pasteboard`) on the right toggles the sidebar.
- Typing-first layout: editor on top, search + item list at bottom.
- Autosave (default on) with configurable idle delay; flush on hide/close.
- Hover `✕` delete on saved items; keyboard Delete/Backspace on focused rows.
- Theme-aware editor border (`pasteboard.editorBorder`).
- Compact icon toolbar: autosave toggle, new, pin, save, panel toggle.
- `pasteboard.sidebarMode` setting for sidebar view vs beside-editor panel fallback.

## 1.0.0

- Initial Pasteboard release.
- Activity Bar webview with GLOBAL and per-workspace tabs.
- Panel toggle, item CRUD, pin, search, and max-item pruning.
